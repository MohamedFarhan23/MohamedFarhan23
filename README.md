# Hey, I'm Farhan

As a kid, I genuinely believed apps and games were handed down by god.
Then I found out that regular people *write* them, with code. That curiosity never wore off, and I've been building ever since.

These days I'm a **Python Backend & GenAI developer** at Zentron Labs, Bengaluru. I started out using AI tools everywhere, got curious about how they actually work under the hood, and ended up building them.
